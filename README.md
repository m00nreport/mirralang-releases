# Mirralang

Ready-to-run builds of Mirralang for macOS (Apple silicon) and Windows. Installed copies look
here for new versions and update themselves from the Mirralang window. There is no source code
in this repository.

Готовые сборки Mirralang для macOS (Apple silicon) и Windows. Установленные копии сами находят
здесь новые версии и обновляются из окна Mirralang.

## Install · Установка

Download from the [latest release](https://github.com/m00nreport/mirralang-releases/releases/latest) ·
Скачай из [последнего релиза](https://github.com/m00nreport/mirralang-releases/releases/latest):

- **macOS** (M1 or newer, macOS 13.3+): `Mirralang-<version>-macos-arm64.zip` — unzip it and
  follow `README.txt` inside · распакуй и следуй `README.txt` внутри.
- **Windows** (10/11, x64): `Mirralang_<version>_x64-setup.exe` — run it · запусти.

After that Mirralang updates itself · Дальше Mirralang обновляется сам.
