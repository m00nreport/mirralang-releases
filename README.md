# Mirralang

Ready-to-run builds of Mirralang for macOS (Apple silicon) and Windows. Installed copies look
here for new versions and update themselves from the Mirralang window. There is no source code
in this repository.

## Install

Download from the [latest release](https://github.com/m00nreport/mirralang-releases/releases/latest):

- **macOS** (M1 or newer, macOS 13.3+): `Mirralang-<version>-macos-arm64.zip`. Unzip it and
  follow `README.txt` inside.
- **Windows** (10/11, x64): `Mirralang_<version>_x64-setup.exe`. Run it.

After that Mirralang updates itself.
